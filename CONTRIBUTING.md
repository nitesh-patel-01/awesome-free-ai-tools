# Contributing

Thanks for helping keep this list honest and useful.

## Rules

1. Only tools with a genuine free tier or free plan. No paid-only tools.
2. No free trials passed off as free. If it is a trial, say so clearly, or do not add it.
3. One honest line each: what it does, what the free tier gives, and what it is best for.
4. Add the tool to the right category in README.md, and to ai-tools.json with the same name, link and category.
5. Check the link opens and the free tier is still listed on the tool's own pricing page.

## How to suggest a tool

Open an issue or a pull request with:

- Tool name and link
- Category
- What its free tier gives
- What it is best for

Keep it short. If a tool stopped being free, open an issue and it will be removed.
